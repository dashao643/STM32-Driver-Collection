# STM32 轻量级外设驱动合集

一些自己开发的关于STM32F1系列的入门级外设驱动库。

## 目前已包含：
1. 定时器单按键、矩阵按键
2. DHT11驱动
3. PWM常用案例(驱动直流电机、舵机)
4. 串口、RS485接收发送
5. Modbus简易协议通信（支持04、05、10功能码）
6. RTC外设实时时钟
7. 数码管驱动
8. WiFi（esp8266，AP模式）
9. ADC采集
10. 软件模拟I2C驱动AT24C64、ssd1306
11. SPI驱动w25q64
