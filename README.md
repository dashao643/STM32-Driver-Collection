# STM32 轻量级外设驱动合集

## 目前已包含：
1. 定时器单按键(未更新)、矩阵按键(三种模式切换)
2. dht11(待优化)、ds18b20
3. tb6612 + 定时器电机案例
4. DMA、IDLE中断串口、RS485接收发送
5. Modbus上层协议(支持04、05、10功能码)
6. RTC外设实时时钟
7. 数码管驱动
8. ADC采集(无注入组)
9. 软件模拟I2C驱动AT24C64、ssd1306
10. SPI驱动w25q64
11. 串口IAP(无外部FLASH)
12. nrf24l01无线模块(单向遥控)
13. CAN通信
14. DS1302时钟
15. iwdg、wwdg(失败)
16. WiFi(ESP8266 AP+STA模式上云)
17. PID电机控制(待优化)
18. LCD屏幕驱动(8080并口)
19. 低功耗(开发中)
